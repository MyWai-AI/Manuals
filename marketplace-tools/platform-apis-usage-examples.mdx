## Obtain an Auth-Token

To consume Platform APIs, you need to have a valid account on the Platform and obtain an authorization token.

For testing purposes, you can obtain a valid token this way:

1. Login with a valid user on the web interface of the Platform you want to connect to the APIs
2. Go to the **Company Settings** page.
3. Find the **Configuration** section at the bottom of the page and expand it.
4. In the Security subsection, you can find your auth token.

The authorization token is valid for 10 hours.

During normal tool execution, when launched from the Platform, the authorization token is provided to the tool automatically via the [Boostrap message](/marketplace-tools/tool-development-guidelines#bootstrap-message).
