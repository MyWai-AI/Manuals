# 3D Viewer

The 3D Viewer is available in multiple sections of the platform and supports visualization of both **single 3D models** and **mixed worlds**, where a full 3D Area is rendered together with **Equipment 3D models placed inside it**.

The viewer appears in the following contexts:

* **Homepage and Company Areas** — displays the 3D representation of an Area, when configured.
* **Data Repository** — displays a standalone 3D file or a 3D file associated with an Event (Event Analysis page).
* **Equipment Details Panel** — displays the 3D model associated with a specific Equipment, when available.

Supported file formats: **GLB**, **SPLAT**, **PLY**.
