title: "AI models"
---

**AI models** lists the LLMs and embedding models that the algorithm services receive with their profile. Open **Algorithms** under **ANALYSIS**. The button is in the page toolbar, next to **Logs**, **Services**, and **Update algorithms**. **MLflow** is in that toolbar when tracking is configured. **AI models** is shown when the role includes **Manage algorithms**.

The panel opens on the right. The heading is **AI models**, under the caption **Algorithm services**, with the line *LLMs and embedding models the algorithms use. The services receive them with their profile.* The close icon leaves the panel.

## The list

The panel has two sections.

* **LLMs** — *The default is preselected when an algorithm asks for an LLM; the user can choose another one for each run.* With no LLM the section says *No LLM: the algorithms that need one are unavailable.*
* **Embedding models** — *The default indexes the equipment documents and embeds the search queries.* With none, the section says *No embedding model: equipment documents are not indexed.*

**Add** at the right of a section opens **New LLM** or **New embedding model**.

Each saved model shows its name. **Default** marks the one preselected for that section. **Platform**, with a lock, means the endpoint and the key come from the platform configuration. The line under the name is the provider, the model, and the API base URL. A platform model says *configured by the platform* instead of the URL.

An LLM line starts with **Chat completions API** or **Responses API**. After that it lists the capabilities that are set, separated by a middle dot. A model that calls tools, reads images, has a known window, and a reasoning effort can read **Chat completions API · Tools · Vision · 32768 tokens · effort low**. The effort is the value you saved, in lower case (**none**, **minimal**, **low**, **medium**, **high**). **Provider default** does not appear on the line. An embedding model reads *Chunks of 500 characters, overlap 100* (the numbers are the ones saved for that model). After a test has measured the vector it adds the size, for example *· 1536 dimensions*.

A warning *Not sent to the services until completed* lists what is still missing. That model is not sent until you complete it.

The icons on the row are:

* play — **Test model**. The answer and the time in milliseconds appear under the row.
* star — **Make default**. It is hidden when the model is already the default, and when the warning above is showing.
* pencil — **Edit model**.
* delete — **Delete model**.

## Add or edit a model

**Name** holds up to 100 characters. Two models cannot share a name. Saving a duplicate shows *Another model already has this name.*

A model marked **Platform** shows the provider and the model in an info box: *Endpoint and key come from the platform configuration and cannot be changed here.* You can still change the name, the capabilities, and whether it is the default. **API** stays on the form when the provider is not Ollama.

For every other model:

| Field | What you enter |
| --- | --- |
| **Provider** | **Azure OpenAI**, **OpenAI-compatible (vLLM)**, or **Ollama** |
| **API base URL** | Azure: the resource URL alone, for example `https://<resource>.openai.azure.com`. vLLM: the URL ending in `/v1`, for example `http://vllm:8000/v1`. Ollama: the server URL, for example `http://ollama:11434`. |
| **api-version** | Azure only. The api-version the deployment supports. |
| **Deployment** or **Model** | **Deployment** on Azure. **Model** for vLLM and Ollama. |
| **API key** | Required for Azure OpenAI. Optional for vLLM and Ollama. On an edit, a saved key stays if you leave the field blank (*Saved. Leave blank to keep it.*). **Remove the saved key** is available when a key is already saved and the provider is not Azure. |

For an LLM that is not Ollama, **API** is **Responses API** or **Chat completions API**. The hint under the field is *Reasoning models accept function tools only on the Responses API.* Ollama does not show this field. An Ollama model is listed as **Chat completions API**.

**Default LLM** or **Default embedding model** marks the model that the section preselects.

An embedding model also has **Chunk size** and **Chunk overlap**, both in characters. The overlap must be zero or more and smaller than the chunk size.

**Missing** names whatever is still empty or invalid. **Test** and **Add** (or **Save** on an edit) stay disabled until that line is gone. **Cancel** closes the form without saving.

## Capabilities

These fields are on an LLM, including a model marked **Platform**.

**Tools** — *The model calls function tools. Test checks it.* A new LLM has **Tools** selected. Clear it when the model does not call tools.

**Test** then sends a request that the model can answer only by calling a tool.

* *The model answered and called the test tool.* **Tools** can stay selected.
* *The model answered without calling the test tool: clear Tools or choose a model that calls tools.*
* If the endpoint rejects the request, the message ends with *to a request with a tool. Clear Tools if the model does not call tools.*

With **Tools** cleared, a successful test says *The model answered.*

**Vision** — *The model reads images.* Select it when the model accepts images. The list then includes **Vision**.

**Context window** — tokens. The hint is *Tokens the server runs the model with. Blank when unknown.* Leave it blank when you do not know the window. When you fill it, use a whole number from 512 to 2,000,000. Any other value is listed under **Missing** as *context window*, and **Test** and **Save** stay disabled. A saved window is shown on the model line as a number of tokens.

**Reasoning effort** — **Provider default**, **None**, **Minimal**, **Low**, **Medium**, or **High**. The hint is *Sent when an agent sets none.* **Provider default** leaves the provider's own effort. Any other choice is shown on the model line, for example **effort low**.

Other test results:

* *The model did not answer in time.*
* *The endpoint could not be reached*, followed by the reason.
* An embedding model that answers shows *The model returned a vector of N values.* The row then shows that many **dimensions**. If a later test measures a different size, the row updates.

The same text appears under the form while you are editing, with the time in milliseconds when the call finished.

## Ollama library

**Ollama library** is on the form when **Provider** is **Ollama**. Until **API base URL** is filled in, it says *Enter the API base URL of the Ollama server first.* The buttons stay disabled. A model marked **Platform** can use the server already stored for that model.

With a URL, the caption is *Choose a model of this Ollama server, download one, or copy one with a larger context window.*

**Installed models** reads the server. Each model is a chip with its name and its size in GB or MB. The chip of the model currently in **Model** is highlighted. Click a chip to put that name in **Model** (*Use this model*). On a **Platform** model the chips stay visible and the tooltip says *The model of a model configured by the platform cannot change.* If the server has nothing yet, the line is *No model on this server yet.*

**Download a model** lists a short selection. The names in the list are **Llama 3 8B**, **Llama 3.1 8B**, **Mistral 7B**, **Qwen 2.5 7B**, **Gemma 2 9B**, **MedGemma 4B (multimodal)**, and **Phi-3 Mini 3.8B**. You can also type a tag from the Ollama library. The hint under an empty field is *A tag from the Ollama library, e.g. llama3.1:8b.* After you pick a listed model, the hint is a short description and an approximate size, for example *About 4.7 GB.* The **MedGemma 4B (multimodal)** hint asks you to check the licensing and appropriate-use terms before you enable it for patient-facing use.

**Download** pulls that model onto the server. A bar and a status line show the progress, for example *downloading · 52%*. When it finishes, the message names the tag, for example *llama3.1 is on the server.* **Installed models** refreshes, and **Model** is set to that tag. On a **Platform** model the download still runs, and **Model** is left as it is.

For an LLM that is not marked **Platform**, a second **Context window** sits in the library, in tokens, with **Check** and **Create copy**. Both stay disabled until **Model** has a name. The hint before you check is *Ollama cuts longer prompts silently: a copy of the model runs with a larger window.* **Check** reads that model and updates the hint: the most tokens the model supports, and either the window it runs with or *runs with the Ollama default*. The hint ends with *A copy shares its weights.* If the field was empty, **Check** fills it with the maximum the model supports.

**Create copy** stays disabled until the window is a whole number from 512 to 2,000,000 and not above the maximum **Check** reported (*This model supports at most N tokens.*). The copy keeps the same weights and runs with the window you asked for. The message names the copy and the number of tokens, for example *Created llama3.1-ctx32768 with 32768 tokens; the form now uses it. Save to keep it.* **Model** and the capability **Context window** switch to that copy. Click **Save** to keep the change. The copy name is the original name with `-ctx` and the token count inserted before a tag, when the name has one.

If the server cannot be read or the download stops, the panel shows the error. Typical lines are *Unable to read the models of the Ollama server*, *Unable to read the context window of the model*, *The Ollama server stopped without an answer*, and *The Ollama server could not be reached*.

## Change the default or delete a model

The star sets the default immediately. You can also select **Default LLM** or **Default embedding model** on the form and click **Save**. Only one model in each section is the default. The first model you save in a section becomes that default even if the checkbox is clear. Clearing the checkbox on the current default does not remove it: choose another model with the star, or select the default checkbox on that other model and save.

**Delete model** asks you to confirm.

* If this model is the default and another complete model of the same kind exists, the panel says *Delete this default LLM?* or *Delete this default embedding model?* and *Choose the new default first.* Pick **New default**. **Delete** stays disabled until you do.
* If this is the only LLM, the panel says *Delete the only LLM? The algorithms that need an LLM stop working until another one is added.*
* Otherwise it asks *Delete this LLM?* or *Delete this embedding model?*

**Cancel** leaves the model in place.
