# Viewer UI

The viewer renders the 3D model and allows full navigation of the scene, including movement, zoom/scale, and rotation.
The interface exposes **three toolbars**, each with a specific function set.

![](/assets/image-42-.png)

1. **Scene / Item Interaction + Camera Controls** _(horizontal toolbar)_
   Tools are ordered **left → right**:
   1. position
   2. rotation
   3. scale
   4. show/hide bounding box
   5. show/hide scene grid
   6. toggle dark/light theme
   7. camera position shortcuts<br>
2. **Items, Helpers, and Algorithms** _(vertical left toolbar)_
   Tools are ordered **top → bottom**:
   1. Export/save scene
   2. Select 3d element from a list
   3. Show/hide axis helper
   4. Toggle animations (if available in the GLB files)
   5. Trigger Algo functionalities (supported only in specifically structured events)<br>
3. **Fullscreen toggle**

## Example interaction

With one file rendered, by selecting it form the toolbar number 2 you can then change its

position/rotation/scale, display its bounding box, show the scene grid and toggle the light theme
