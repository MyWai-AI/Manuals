---
title: "File System Watcher Adapter"
---

The File System Watcher Adapter allows to move data into the MYWAI system by using a simple file drop mechanism into a specific folder on the Edge device.

This Adapter must be configured entering the following information:

* **Filter**: a filter for the desired file type, for example "\*.png".
* **Path**: the absolute path of a file system folder of the Edge device to be monitored.

The adapter expects to receive appropriate file type(s) for the specific measure(s) associated to the sensor.
