# Glossary

<table><thead><tr><th width="204">Term</th><th>Meaning</th></tr></thead><tbody><tr><td>Equipment</td><td>A physical machine or industrial device monitored and/or controlled by the MYWAI Platform. It is typically connected through an Edge device using OPC-UA or other industrial communication protocols.</td></tr><tr><td>Edge</td><td>The MYWAI Edge software/hardware component responsible for interfacing with field Equipments, collecting/processing data locally, and securely communicating with the MYWAI AI services and Platform.</td></tr><tr><td>GDS</td><td>Stands for <strong>Global Discovery Server</strong>, an OPC Foundation component that provides centralized discovery, registration, and trust management services for OPC-UA clients and servers (including certificate validation and authority delegation).</td></tr><tr><td>OPC-UA</td><td>An interoperable, platform-agnostic communication standard defined by the OPC Foundation, enabling secure data exchange and remote control between industrial devices (servers) and applications (clients).</td></tr><tr><td>PKI</td><td>Stands for <strong>Public Key Infrastructure</strong>. A framework used to issue, manage, distribute, and revoke digital certificates and cryptographic keys. PKI enables authentication, integrity, and encrypted communication between MYWAI Platform components (e.g., Edge, Equipments, Platform services).</td></tr><tr><td>Docker</td><td>A containerization platform that packages software and its dependencies into isolated containers. MYWAI uses Docker to ensure consistent runtime environments, simplify deployment of Edge and Platform services, and enable scalable operation across heterogeneous infrastructures.</td></tr><tr><td>AASX</td><td>A packaged file format used to represent an <strong>Asset Administration Shell</strong> (AAS) according to the Industrie 4.0 / IEC 63278 standard. An AASX file is typically a ZIP container bundling the AAS metadata (in JSON or XML) together with related resources (e.g., submodels, documentation, digital nameplate, or configuration artifacts). It provides a portable digital representation of an asset for interoperability across industrial systems.</td></tr><tr><td>Marketplace Tool</td><td>A plug-in component of MYWAI that allows to augment the capabilities of the MYWAI Platform, offering users a powerful extension to interact with and enrich their data. This specialized tool enables the creation of custom user interfaces (UIs) tailored to perform specific tasks, significantly improving workflow efficiency and data interaction.</td></tr><tr><td>Adapter</td><td>A MYWAI software component that translates data/protocols from an Equipment or Edge device into the format expected by the Platform.</td></tr><tr><td>Blockchain</td><td>A <strong>decentralized and immutable ledger</strong> used to record transactions or data in a transparent and verifiable manner.<br>It consists of a continuously growing list of records—called blocks—linked and secured using cryptographic hashes.</td></tr><tr><td>IOTA</td><td>A distributed ledger technology (DLT) designed for the <strong>Internet of Things (IoT)</strong>, enabling <strong>feeless, scalable, and energy-efficient</strong> data and value transfers.<br>Unlike traditional blockchains, IOTA uses a <strong>Directed Acyclic Graph (DAG)</strong> structure called the <strong>Tangle</strong>, where each transaction validates two previous ones, removing the need for miners and transaction fees.<br>In MYWAI, IOTA is used to <strong>certify data integrity</strong> by anchoring the cryptographic hash of AASX files stored on IPFS, ensuring immutability and verifiability.</td></tr><tr><td>IPFS</td><td><strong>IPFS (InterPlanetary File System)</strong> is a <strong>peer-to-peer distributed storage network</strong> that enables permanent and decentralized file hosting.<br>Each file stored in IPFS is identified by a <strong>Content Identifier (CID)</strong>, a cryptographic hash representing the exact file content.<br>In MYWAI, IPFS is used to store <strong>AASX files</strong> generated from Events and Anomalies before certification, ensuring <strong>data persistence</strong>, <strong>content immutability</strong>, and <strong>integrity validation</strong> through the CID.</td></tr></tbody></table>
