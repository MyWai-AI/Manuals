# Certifications

The **Certifications** page displays all certifications recorded on the **IOTA blockchain**.\
The following data types can be certified: **Events**, **Anomalies**, and **Datasets**.

The **MessageId** shown on this page is the unique identifier of the certification transaction recorded on the **IOTA Tangle**. It is the cryptographic reference that links the certified data to its immutable blockchain record.

Practically, the MessageId can be used to **verify integrity and existence** of the certification. By querying the IOTA network with this identifier, anyone can retrieve the corresponding message and confirm that the data was published at a specific point in time and has not been altered since. This enables independent verification without relying on the originating system.
