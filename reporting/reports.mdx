# Reports

The Reports section allows to configure **Widgets** and **Reports**, that are a sort of Dashboard of widgets.

### **Widgets**

Widgets are of two main types:

#### **Real-time data**

Charts for **displaying real-time Equipments data**.

* Can be **Line chart**, **Bar chart** or **Gauge**
* Works for a specific **Equipment Type**
* Can filter items on **Sites** and **Areas**
* Can show only specific **Measures**
* Visibility can be associated to specific **Roles** only

#### Anomalies

List of **recent** [**anomalies**](/reporting/anomalies) **detected**.

* Works for a specific **Equipment Type**
* Can filter items on **Sites** and **Areas**
* Can show only specific **Measures**
* Visibility can be associated to specific **Roles** only

To create a Widget, access the Reports page and click on "Add New Widget" button, then follow the wizard to fill all the required information.

### Report (Dashboard)

Reports represent a collection of Widgets. In a Report you can insert any widget you defined and place and resize it in the available page space.

When inserting a Widget in a Report, you can define:

* A custom **title**, different from the Widget title
* The data visualization **refresh period**
* The **time range** of real-time data to show (i.e. last 10 minutes)

<Warning>
Gauge type widgets will always show the last value recorded, even if it was in the past. The timestamp associated to the value is displayed.
</Warning>

A Report can be shown:

* From the **Reports list page**, clicking on "Show report" ![](<../.gitbook/assets/image (2).png>) button on the Report row.
* Attached in the **platform home page**. You can attach the report to the homepage by clicking the "Homepage" <img src="../.gitbook/assets/image (3).png" alt="" data-size="original">button on the Report row and optionally choose the Roles ot the users that should be able to see the report.
