# Labels approval workflow

Each **label** (or rather, each tag) can undergo an approval process in which one or more users can interact to validate it, for example, before training an algorithm.

You can explore the labels created in the Labels section from the navigation menu.

There are four distinguishable sections:

1. **Labels**: This represents a collection of all the labels created by the user that have not yet been associated with approval workflows. You can group multiple labels under a single tag, which represents a logical grouping of examples of the same type of label. For instance, multiple labels can identify the same type of anomaly and can, therefore, be grouped under the same category. To create a tag, select a label and choose "Promote to root" from the toolbar. You can add other "examples" to the tag by dragging and dropping nodes from the label navigation tree. Labels that are already grouped and trained with an algorithm cannot be promoted to tags. Only tags, and not individual labels, can be subjected to the approval process using the button provided on the toolbar. When opening the dialog, specify the "Description" field and enable users or roles responsible for reviewing. At the end of the process, a notification email will alert the specified users or members of the configured group.
2. **Pending**: This list is accessible by both the initiator of the approval workflow and the user assigned as the reviewer. In the latter case, however, functionalities for removing labels belonging to the tag and the ability to complete ("Complete") or reject ("Abandon") approval will be enabled. The option to deny approval is also available to the user who initiated the workflow.
3. **Approved**: After the approval cycle is completed and the "Complete" procedure is performed in the previous step, the workflow's author can check in this section the tags that have been completed and approved by the designated reviewer.
4. **Abandoned**: This list displays workflows that have not been approved by the reviewer.
