# Algorithms

The MYWAI Algorithms Environment provides a set of ready-to-use algorithms that can be executed directly from the MYWAI Platform.
These algorithms cover the most common analytical needs such as anomaly detection, classification, clustering, dimensionality reduction, generative modelling and object detection.

Each algorithm is delivered within the MYWAI Algorithms Docker Environment and becomes immediately available in the platform once the service is running.

Alongside built-in algorithms, MYWAI also allows the creation, registration and execution of **custom algorithms**, using the same SDK, structure and integration process used for product algorithms. This ensures a unified approach to designing, deploying and maintaining analytical models inside the MYWAI ecosystem.

***

### Algorithm Categories

Built-in (product) and custom algorithms are organized into the following categories:

* Anomaly Detection
* Classification
* Clustering
* Dimensionality Reduction
* Generative Models
* Object Detection / Pattern Recognition

Each algorithm belongs to exactly one category and specifies the type of data it processes (time series or images).

## Product Algorithms and Custom Algorithms

The MYWAI Platform supports two types of algorithms:

### 1. Built-in Product Algorithms

These are the models listed above, already packaged within the MYWAI Algorithms Environment.
No installation or configuration is required to use them.

### 2. Custom Algorithms

Users or MYWAI technical teams can develop custom algorithms tailored to specific business requirements.
Custom algorithms:

* follow the **same structural format** as product algorithms,
* use the **same SDK and integration framework**,
* are published by an **algorithm service** you register on the platform (name, description, tag, category, parameters come from that service),
* and are executed by the same runtime used for product algorithms.

Once the service is saved, its algorithms appear on the **Custom Algos** tab and follow the same training and execution workflow as product algorithms. The registration steps are in [Custom Algorithms](/analysis/algorithms/custom-algorithms).

## How Algorithms Are Used in the Platform

**Algorithms Management** lists every algorithm the platform knows about.

* **Product Algos** and **Custom Algos** split the built-in catalog from the services you added.
* **Manage Services** registers, edits, or removes a custom algorithm service.
* **Update Algorithms** reloads the catalog from those services.
* **View algorithm** opens the definition of one row.
* The same algorithms are then selected in [Training](/analysis/training) and in data analysis.
