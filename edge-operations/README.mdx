# Edge Operations

MYWAI performs Edge operations with the Edge software installed on the company site.

## MYWAI Edge

MYWAI Edge connects to the equipment using configured adapters, executes orchestrator flows, and integrates with AI modules for edge AI.

The same installation also starts the **GDS** (Global Discovery Server) on that machine. You do not install the GDS as a separate product.

The GDS is the OPC UA service that registers applications and provides the certificates they use to connect securely. In MYWAI it covers the Edge and the OPC UA servers of the equipment. When the Edge package starts, two containers run together: the Edge and the GDS. After they are running, accept the GDS on the platform so it can receive its certificate. The details are in [Edge Installation](/edge-operations/edge-installation-v3.0).
