The MYWAI **GDS** is designed to oversee security for both Edge devices and OPC UA Servers.

GDS stands for **Global Discovery Server** and is a technology defined and standardized by the OPC UA Foundation. Here more information about the GDS technology:\
[https://reference.opcfoundation.org/GDS/v105/docs/6](https://reference.opcfoundation.org/GDS/v105/docs/6)

## System Requirements

MYWAY Edge runs on:

* Microsoft Windows devices: Windows 10 or 11.
* Linux devices with Ubuntu 22.04.

The GDS is provided as a Docker image.
