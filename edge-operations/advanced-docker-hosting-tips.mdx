## **Configuring Docker service to start on boot**

On Windows, Docker typically runs as a service. To ensure it starts on boot:

1. Open the Windows Services manager (you can search for "Services" in the Start menu).
2. Find the Docker service (usually named `Docker Desktop Service` or something similar).
3. Right-click on the service and select "Properties".
4. In the "Startup type" dropdown, select "Automatic".
5. Click "Apply" and then "OK" to save your settings.

## Configure automatic updates

It is possibile to configure the Edge device so when a new version of the MYWAI edge or algorithms images are available, the container is automatically updated.

The automatic image update is managed with _watchtower._\
Create the following docker container that will take care of the software update:

```bash
docker run -d --name watchtower --restart always -e REPO_USER=mywai-pull -e REPO_PASS=NkSyPUQ8Te2uAh7HIHb8jCERAHPoMdhqeoBH3EuFjM+ACRCWexoT -v /var/run/docker.sock:/var/run/docker.sock containrrr/watchtower mywai-edge mywai-algo --interval 300 --cleanup
```

Please refer to watchtower documentation for more details on parameters and use the `--schedule` argument to define suitable time windows for performing updates.

## Configure automatic login and container startup for non Windows Server distributions

It is possible to configure windows to automatically start up your containers on system boot. The easiest way to achieve so is to enable the automatic sign in procedure from windows due to the requirements of the Docker Desktop runtime and privileges needed for a correct execution.

### Enable Docker automatic startup

1. Open the Docker Desktop application.
2. Click on the Settings icon (gear shaped icon) found on the top bar.
3. Navigate to the `General` menu entry from the left side menu.
4. Check the **Start Docker Desktop when you sign in to your computer** option.
5. Click on **Apply & Restart**.

### Enable automatic Docker Desktop Service

1. While holding the Win Key press the letter 'R', type `services.msc` and hit enter.
2. From the list of services look for `Docker Desktop Service` and double click on it. If you have un ordered entries and find it difficult to find the service you can reorder the list by alphabetical order by clicking on the column header **Name**.
3. From the **Startup type** dropdown menu choose `Automatic`.
4. Click on **Apply** and then **Okay**.

### Enable Windows automatic login

1. While holding the Win Key press the letter 'R', type `regedit` and hit enter.
2. If the system requires higher privileges, click on yes to continue.
3. Navigate from the left side menu of the newly opened window to the following path:\
   _`HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\WindowsNT\CurrentVersion\PasswordLess\Device`_
4. Click on the `Device` option to see the keys present in the registry at the right side of the menu.
5. Double click on the `DevicePasswordLessBuildVersion` entry.
6. Change the Value Data entry from 2 hexadecimal to 0 hexadecimal.
7. Click on Ok and close the window.
8. Hold again the win key and press the letter 'R'.
9. Type `netplwiz` and hit enter.
10. Click on the **Administrator** account.
11. Remove the check mark from the "**Users must enter a user name and assword to use this computer"** option.
12. Click on apply.
13. A prompt will be shown with the username field already filled in. Insert the selected user's password in both fields.
14. Click on **Ok**.
