Open **Data Repository > Documents** to browse the document library. Use the **Site**, **Area**, and **Equipment** filters to narrow the list. **More filters** includes title, tags, author, date, file type and search text.

You can also open **Documents** on an equipment's details panel. **Show inherited** includes documents from the equipment's parent scopes that your roles let you read.

## Upload and organize

With **Manage documents**, click **Upload**, choose a file, and fill in the title, description and any comma-separated tags. Set **Scope** to the organization, a site, an area, or an equipment. The scope determines where the document belongs. Your roles and document rules determine who can read it.

Use the magnifying glass in the list to open the document. PDF, image and text files can be previewed. Use **Download** to save a copy locally.

To edit a document, change the title, description, tags or scope and click **Save metadata**. To restrict access, choose **Selected roles** under **Visible to**, select the roles and click **Save visibility**. Choosing roles by name also requires permission to view roles. Those roles must still be able to reach the document's scope.

## Versions and deletion

- Under **New version**, choose the file, pick **Minor** or **Major**, and click **Upload version**.
- Under **Versions**, use **Preview** to inspect a version and **Make current** to switch the one shown by default.
- To remove a document from the library, use **Delete**. Administrators with **Manage documents** can find it again using **More filters > Include deleted**.

For how agent retrieval is configured, see [Document search and the Embedder](/3.2/analysis/algorithms/document-search).
