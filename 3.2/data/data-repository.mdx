---
title: "Data Repository"
---

The **Data Repository** allow to collect an manage subset of data that are in the system, particularly the one that are intended to be used for ML algorithm training and supervision.

Data Repository can contain:

1. Events that are imported via ZIP+CSV files.
2. Events that are generated automatically via Edge side (when the Edge is by intention configured to do so).
3. Events that has been manually defined in the Data Analysis page.
4. Blob data (images, audios, videos) manually uploaded in the system.
5. Timeseries data, manually uploaded in the system.

The Data Repository allow to categorize and organize these data, by applying **Labels** and organizing them into **DataSets**, with the goal to train supervised ML algorithms.

In general, only few data that is live recorded by the Edge in direct connection to the Equipment are stored in the Data Repository. This is generally done in special moment on which you want to collect an important amount of events to label them and collect them in DataSets for training or re-training purposes.

You can anyhow create new Events anytime browsing the data timeline and defining new Events via the Data Analysis page.
