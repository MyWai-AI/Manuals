---
title: "3D Viewer"
---

The 3D Viewer is available in multiple sections of the platform and supports visualization of both **single 3D models** and **mixed worlds**, where a full 3D Area is rendered together with **Equipment 3D models placed inside it**.

The viewer appears in the following contexts:

* **Homepage and Company Areas** — displays the 3D representation of an Area, when configured.
* **Data Repository** — displays a standalone 3D file or a 3D file associated with an Event (Event Analysis page).
* **Equipment Details Panel** — displays the 3D model associated with a specific Equipment, when available.

Supported file formats: **GLB**, **SPLAT**, **PLY**.

## 3D files and toolkit views

Where a ThreeD file has a matching [toolkit view](/3.2/marketplace-tools/toolkits), it opens
in the native viewer even if the toolkit is configured to **Open by default**, unless you
have already chosen a view in this browser. Choose the toolkit's button to open it, or
**Both** to show it alongside the native viewer. On narrow screens the two panels stack.

In Historical, selecting ThreeD signals also keeps the native chart and 3D viewer as the
starting view. **Both** keeps the chart below the toolkit. The browser remembers your
choice per user and 3D place. If a toolkit fails, the native content returns for that page
without changing the remembered choice. See [Using toolkit views](/3.2/marketplace-tools/toolkits/using-toolkit-views).
