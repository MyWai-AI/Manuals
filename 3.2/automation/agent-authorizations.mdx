---
title: "Agent authorizations"
---

In **Automation > Agent authorizations**, review the permissions you have delegated for agents that run on a schedule or in response to an event. These runs use the identity of the user who authorized them.

With permission to view agents, you can see your own authorizations. Users with permission to manage agents can see all users' authorizations. Filter by **Status** and use **Reload** to refresh the list.

To stop an authorization, click **Revoke** on the active row and confirm. Its owner needs to authorize the schedule again before it can run under that identity.
