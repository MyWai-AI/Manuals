## Agents

When MAICOL is configured, open **Automation → Agents**. Use **Search agents** to find an agent, then select **Chat** to start a conversation. Use **MAICOL chat** at the top of the page to show or hide the floating widget for the current browser session.

Ask MAICOL to open an equipment's analysis, a document, a model report or an agent. You can also ask MAICOL to prepare processing or inference from equipment analysis. The Platform opens the dialog with the available inputs filled in. Review them and select **Run** to start the algorithm.

Use the widget's size control to switch between compact, medium and full screen. Select **Minimize** to return to the floating launcher, which uses the MAIA logo by default.

### Ask about documents

Ask MAICOL to list the documents you can access, optionally by title or equipment. The list includes documents that are still waiting to be indexed. Questions about the contents of Platform documents use the indexed text. When you open chat from an equipment or a selected document, MAICOL uses that selection.

To ask about a PDF from your computer, attach it in chat and ask your question. MAICOL cites the pages it reads. For scanned pages, it uses text recognition in English, Italian and German when the OCR tools are available. If a page cannot be read, share a clearer scan or a PDF with selectable text.

### View equipment, sensors and charts

Ask MAICOL for a table of equipment, sensors and measurements. The results follow your Platform permissions and the equipment selected in the chat.

Ask for a chart by sensor name, for example “Plot DG1”. Include a signal and dates when you want a specific measurement or period. With no dates, the chart shows the latest hour containing observations. If several sensors match, provide the full name. The charts use the units of the measurements and appear in the conversation.

### Analyze data with Python

When Python analysis is enabled, attach a data file and ask MAICOL to calculate a result, make a statistical comparison, or generate a custom plot. For example, ask for the median and a box plot of a column in a CSV or Excel workbook. Plots appear in the conversation and generated PNG, CSV, JSON and TXT files can be downloaded from the result.

Each execution starts in a fresh environment. When the Python workers are busy, the result card shows whether the analysis is waiting or running. It updates when the result is ready, including when you reopen the conversation. To continue an analysis, ask MAICOL to use a previous output from the same conversation while the file is still available.

### Create equipment with synthetic data

Ask MAICOL for an equipment name and the measurements you want to simulate. In **Ask** mode, review equipment creation and then sample import in the approval cards. MAICOL labels the import as synthetic. An import shown as pending is still processing. Ask for its status before using the samples.

### Agent authorizations

Under **Run and monitor**, select **Authorizations** to review background access granted to MAICOL. Select **Revoke** and confirm to stop future runs under that authorization. Agent managers can review authorizations for all users.

When MAICOL scheduling is enabled, **Schedule** on an agent's row opens its recurring schedule form. **Authorizations** shows the available timing information. Select **Orchestrator** under **Run and monitor** to manage existing Platform workflows if your role allows it.

Agent managers can switch between **For people** and **Helpers** in the catalogue. Helpers are available to other agents and scheduled runs. Select **Edit** to open an agent's flow or **Access** to manage its user and equipment assignments. **Edit agents and drafts** opens the full editor list.

**Build** links to **Tools** for MCP servers, **Prompts** for reusable instructions and **Response cards** for chat results. **Run and monitor** also links to **Traces** and **Chat widget**. Each editor has its own URL. Select **Agents** at the top to return to the catalogue. Browser Back and Forward work within the area without reloading the Platform.

### Build a flow and choose the widget default

In **Agents**, select **Edit agents and drafts**. The **Drafts** filter shows in-progress work. **New agent flow** lets you pick who can talk to the agent. You can change **Who talks to it** later without republishing a published agent.

Use the **Single agent** template to start with **Start → Agent → End**. Select the Agent block to choose its model, instructions and tools. To add another block, choose it from the palette. Drag from the right handle of the previous block to the new block's left handle. Select a block or connection to edit its settings. For multiple agents, connect Agent blocks in sequence or use a **Delegate** connection so an agent can call a specialist. Use a **Sub-flow** block to reuse a published flow.

Select **Check** and **Publish**, then use **Test run** to try a message. The built-in **MAICOL assistant** appears in the Flows list. The **Chat widget** column shows which agent answers by default. Select **Use in chat** next to a published flow for people, or next to the built-in assistant.
