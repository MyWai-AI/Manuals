MYWAI performs Edge operations with the Edge software installed on the company site.

## MYWAI Edge

MYWAI Edge connects to the equipment using configured adapters, executes orchestrator flows, and integrates with AI modules for edge AI.<br /><br />The same installation also starts the GDS (Global Discovery Server) on that machine. You do not install the GDS as a separate product.<br /><br />The GDS is the OPC UA service that registers applications and provides the certificates they use to connect securely. In MYWAI it covers the Edge and the OPC UA servers of the equipment. When the Edge package starts, two containers run together: the Edge and the GDS. After they are running, accept the GDS on the platform so it can receive its certificate. The details are in [Edge Installation](/3.2/edge-operations/edge-installation-v3.0/index).<br /><br /> The algorithmic service runs the AI algorithms on that same machine. It is a separate package: install it after the Edge and the GDS are running. Its start script runs three containers, `base`, `vision`, and `neuromem`. They connect to the Mosquitto broker of the Edge and use the Edge storage folder. You do not accept this service on the platform. The details are in [Edge Installation](/3.2/edge-operations/edge-installation-v3.0/index).
