### GDS on the same machine

The current Edge package starts the GDS together with the Edge. Inside the installation the Edge reaches that GDS at `opc.tcp://gds:58810/GlobalDiscoveryServer`. You set the GDS ID and the GDS password in `edge.env` while you [install the Edge](/3.2/edge-operations/edge-installation-v3.0/index#the-gds).

### Expose the Edge MQTT Broker for External Access

If you need to integrate external systems with the Edge MQTT Broker running inside the container, you must make the broker accessible from outside. To do this, expose its port by adding the following option to the `docker run` command:

```
-p 1883:1883
```

This maps port **1883** of the container to port **1883** on the host, allowing external clients to connect to the MQTT Broker.

See also [this appendix](/3.2/appendix-2-edge-data-access-and-mqtt-broker-integration) for more information.

### Connecting to dedicated or on-premises platform installation

To connect the Edge to platforms with dedicated hostnames or on-premises installation, you can't use the _IotHub\_\_TenantName_ environment variable, but you need to explicit set the needed endpoints of the different services:

```bash
-e BlobStorage__SftpHttp__PublicServer=[blob storage sftp server hostname]
-e BlobStorage__SftpHttp__Port=[blob storage sftp server port]
-e BlobStorage__SftpHttp__PublicUrl=[blob files access url (https)]
-e IotHub__server=[iothub hostname]

```

### Offline Configuration

In cases where the Edge device operates in stand-alone mode, not connected to the Platform, it needs to be configured manually using the following procedure:

1. Download the json configuration file from the Platform: go on the Edges list page, click on the Details button on the Edge you want to manually configure and then click on the Download Edge Configuration button. A .json file will be downloaded with name`edge_config_<edge_id>.json`
2. Copy the file in the `EdgeStorage`folder on the Edge machine.
3. Install Mosquitto on the Edge host machine.
4. Run the following command from the host machine, replacing:\
   `[EdgeId]` with the local IP address of the Edge container\
   `[Config file name]` with the name of the file downloaded from the previous step\
   `[MQTTUsername]` the username to log in into MQTT server. The default value is "edge". The actual value can be found in the Edge appSettings.json file.\
   `[MQTTPassword]` the password to access the MQTT server. The actual value can be found in the Edge appSettings.json file.\
   \
   On Windows, the path to be provided in the -m parameter must start with "C:\EdgeStorage\\\[Config file name]".

```
mosquitto_pub -h [EdgeIp] -p 8883 -t UpdateConfigurationFromFileSystem -m "/EdgeStorage/[Config file name]" -u [MQTTUsername]-P [MQTTPassword]

```
